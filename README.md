# Unimi Schedule Telegram Bot

Локальный Telegram-бот расписания курса **BBJ** (Università degli Studi di Milano).

## Возможности

- Reply-клавиатура: сегодня / завтра / эта и следующая неделя / месяц
- Элективы: свои пары с периодичностью, просмотр / правка / удаление
- Кнопка **«Проверить на сайте»**
- Вечернее напоминание о завтрашних парах (с учётом элективов)

## Элективы

Расписание (портал + элективы) **общее** для всех пользователей бота. Смотреть могут все; менять и удалять электив — только тот, кто его добавил.

Кнопка **📚 Элективы**:

1. **Добавить** — пошаговый ввод: название, препод, тип, дни, время, аудитория, дата старта, число недель, периодичность (каждую неделю / раз в 2 недели)
2. **Список** — все элективы; кнопки «Изменить» / «Удалить» только у своих
3. Элективы помечаются ⚡ в общем расписании

## Переводы (i18n)

Все пользовательские тексты и подписи кнопок — в одном файле:

`bot/locales/ru.py`

В коде: `from bot.i18n import t, locale` → `t("start.hello", sub="…")`.

Чтобы добавить язык: создай `bot/locales/en.py` по образцу `ru.py` и зарегистрируй в `bot/i18n.py`.

## Быстрый старт

```bash
python -m venv .venv
source .venv/Scripts/activate
pip install -r requirements.txt
cp .env.example .env
python -m bot
```

## Настройки

```env
REMINDER_HOUR=20
REMINDER_MINUTE=0
REMINDER_TZ=Europe/Rome
ELECTIVES_PATH=data/electives.json
```
